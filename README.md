# 🛡️ PhishGuard — Phishing URL Detection Tool

PhishGuard is a browser-based cybersecurity tool that analyzes website URLs and identifies common characteristics associated with phishing and suspicious links.

The project provides a clean security dashboard where users can scan URLs, view a risk score, understand detected indicators, and review their recent scan history.

> ⚠️ **Educational Project:** PhishGuard is designed for cybersecurity learning and awareness. It is not a replacement for professional threat-intelligence or antivirus services.
